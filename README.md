# Stock Waste Risk Analyzer

A Python-based inventory analysis project that analyzes stock levels and demand-related information to identify products that may require attention.

## What the Project Does

The project reads inventory data from a CSV file and analyzes the products based on their current stock and demand information.

It identifies:

- Slow-moving products
- Products with a potential stock-out risk
- Estimated days of stock remaining
- Demand trend
- Priority score
- Reason for the assigned priority

The results are displayed as a Final Priority Action List.

The project also exports the results to a CSV report.

## Input

The project uses an inventory CSV file as its input.

## Output

The program generates a priority list showing products that require attention, along with their stock information, estimated days remaining, demand trend, priority score, and reason.

It also generates:

final_priority_report.csv

## Technologies Used

- Python
- CSV
- Scikit-learn
